AgentLeash

Let AI agents pay in tUSD8 - on a leash you control.

QDay Aevum Testnet

How it works

  1. Owner deposits tUSD8 into the AgentLeash vault.
  2. Owner gives an agent a leash: max per payment, max per 24h, expiry, approved merchants.
  3. Agent pays invoices by itself. The contract blocks anything outside the leash.
  4. Owner can revoke the agent or pause the vault in one click. Every payment is on-chain.
